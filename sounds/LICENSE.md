All `.wav` files in this folder were **synthesized from scratch** by
[`tools/generate_sounds.py`](../tools/generate_sounds.py) using only sine
waves, square waves, and random noise. No third-party recordings or sample
packs were used.

## Swapping in other royalty-free samples

If you'd rather use recorded drums, replace the files here with samples of
the same name from a royalty-free / CC0 source, for example:

- [Freesound.org](https://freesound.org) — filter by license **"Creative Commons 0"**
- [99Sounds](https://99sounds.org) — free, royalty-free drum packs
- [SampleSwap](https://sampleswap.org) — royalty-free drum hits

Always double-check the license of each individual file before using it.
